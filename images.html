Images!

Images don't have a closing tag cause it's a self-closing tag!

We use the <img> tag!

We also use an <alt> tag for screen readers.

We can do the following inisde the <image> tag:

We can refer to images via a url path or local source path via <src='pathname'>.

We can also use <height> and/or <width> inside the <src> tag to resize an image.
