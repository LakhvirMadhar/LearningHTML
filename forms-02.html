Checkboxes

Checkboxes lets you choose multiple options at once. Each checkbox is independent. Let's use pizza as an example.

Radio Buttons

Radio buttons force the user to pick one option from a group. They must share the same name attribute to be linked as a group. The shared name is what tells the browser that these radio buttons belong together and only one can be selected at a time.
